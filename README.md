# Project 200

Nền tảng học tập theo project cho sinh viên. Mỗi project có một level từ 0 đến 5, thuộc
một track chuyên môn, rèn một số skill và có thể yêu cầu hoàn thành trước một số project
tiên quyết. Người dùng nộp bài, được chấm, nhận XP và badge, rồi được gợi ý project tiếp
theo dựa trên tiến độ của chính mình.

## Cấu trúc

| Thư mục | Nội dung |
|---|---|
| [`backend/`](backend/) | API viết bằng FastAPI và SQLAlchemy, dùng SQLite |
| `frontend/` | Giao diện web, sẽ bổ sung sau |

Hướng dẫn cài đặt và chạy nằm trong [`backend/README.md`](backend/README.md).
